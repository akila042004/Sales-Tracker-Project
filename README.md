Sales Tracker in Google Sheets

Project Overview

This project is a Sales Tracker developed using Google Sheets as part of my Veda Technology internship.

Objective

To create a simple sales tracking spreadsheet that automatically calculates daily, weekly, and monthly sales totals.

Tools Used

- Google Sheets

Features

- Daily sales tracking
- Weekly sales summary
- Monthly sales summary
- Automatic sales calculations
- SUMIFS formulas
- Data validation
- Organized raw data and summary sheets

Project Structure

- Raw Data: Stores sales information.
- Summary: Displays daily, weekly, and monthly sales totals.

Formulas Used

- Multiplication formula for total sales.
- SUMIFS for date-based sales calculations.
- EOMONTH for monthly calculations.

Conclusion

This project helped me improve my Google Sheets skills, including data organization, formulas, automatic calculations, and data validation.
